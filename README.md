# DSY1102 --- Desarrollo Orientado a Objetos

Repositorio oficial de clases y ejemplos de código de la asignatura
**DSY1102 --- Desarrollo Orientado a Objetos**.

## Sobre la asignatura

Desarrollo Orientado a Objetos es una asignatura de la línea formativa
**Desarrollo de Soluciones de Software**. Su propósito es que los
estudiantes aprendan a desarrollar soluciones de software utilizando el
**paradigma de Programación Orientada a Objetos (POO)**, aplicando
buenas prácticas para responder a requerimientos y problemas de negocio.

Durante el semestre se trabajará progresivamente desde los fundamentos
del lenguaje y la programación orientada a objetos hasta la construcción
de aplicaciones de escritorio con interfaz gráfica y persistencia de
datos.

El trabajo práctico de la asignatura se desarrollará principalmente
utilizando **Java**.

## ¿Qué aprenderemos?

La asignatura se organiza en tres grandes etapas:

### 1. Fundamentos de Programación Orientada a Objetos

Comenzaremos construyendo las bases necesarias para programar utilizando
el paradigma orientado a objetos.

Entre los principales contenidos se encuentran:

-   Fundamentos del paradigma orientado a objetos.
-   Tipos de datos y operadores.
-   Estructuras de control.
-   Métodos, parámetros y valores de retorno.
-   Clases, objetos y abstracción.
-   Atributos, constructores y métodos.
-   Encapsulamiento.
-   Herencia.
-   Clases abstractas e interfaces.
-   Polimorfismo.
-   Manejo de excepciones.
-   Colecciones.

El objetivo de esta etapa es aprender a representar problemas mediante
clases y objetos que colaboran entre sí.

### 2. Interfaces gráficas y persistencia en archivos

Una vez dominados los fundamentos de POO, avanzaremos hacia el
desarrollo de aplicaciones de escritorio.

Trabajaremos con:

-   Maven.
-   JavaFX.
-   Scene Builder.
-   FXML.
-   Componentes de interfaz gráfica.
-   Eventos de usuario.
-   Patrón Modelo-Vista-Controlador (MVC).
-   TableView y ObservableList.
-   Navegación entre vistas.
-   Validación de formularios.
-   Persistencia de información mediante JSON.
-   Capas Repository y DAO.

En esta etapa construiremos aplicaciones que permitan al usuario
interactuar con los objetos mediante una interfaz gráfica y conservar
información entre ejecuciones.

### 3. Integración con bases de datos

Finalmente, integraremos nuestras aplicaciones con una **base de datos
relacional**.

Se abordarán contenidos como:

-   Fundamentos necesarios de SQL.
-   Conectividad entre Java y una base de datos.
-   Configuración de conexiones.
-   Consultas y manipulación de datos.
-   Sentencias parametrizadas.
-   Operaciones CRUD.
-   Patrón DAO.
-   Integración de la base de datos con la interfaz gráfica.
-   Organización del proyecto por capas.
-   Control de versiones y trabajo colaborativo.

El propósito de esta etapa es construir aplicaciones de escritorio
completas, organizadas y capaces de almacenar información de forma
persistente.

## ¿Para qué existe este repositorio?

Este repositorio tiene como objetivo centralizar el **código
desarrollado durante las clases de la asignatura**.

Aquí se irán publicando progresivamente:

-   Ejemplos desarrollados durante las clases.
-   Proyectos Java utilizados para explicar los contenidos.
-   Código comentado y trabajado paso a paso.
-   Ejercicios prácticos.
-   Mini desafíos de programación.
-   Ejemplos complementarios para reforzar contenidos.

El repositorio está pensado como un **material de apoyo al
aprendizaje**. El código no reemplaza la explicación realizada en clases
ni las actividades disponibles en AVA.

La recomendación es revisar cada ejemplo, ejecutarlo, modificarlo y
experimentar con él para comprender su funcionamiento.

## Metodología de trabajo

Las clases tendrán un enfoque principalmente práctico.

La idea no es solamente observar código terminado, sino comprender
**cómo se construye una solución desde cero**, analizar el problema,
escribir el código paso a paso, ejecutarlo, detectar errores y
mejorarlo.

Durante el semestre iremos aumentando gradualmente la complejidad de los
proyectos hasta integrar programación orientada a objetos, interfaces
gráficas, persistencia y bases de datos.
